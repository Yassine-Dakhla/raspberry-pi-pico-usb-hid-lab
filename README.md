# Raspberry Pi Pico Ducky Lab

A hands-on USB HID keyboard emulation project using an original Raspberry Pi Pico and CircuitPython, based on [dbisu/pico-ducky](https://github.com/dbisu/pico-ducky).

## Hardware

- Raspberry Pi Pico (original, without Wi-Fi)
- USB data cable
- Computer for testing

## Test Result

The Pico was connected over USB and successfully opened a terminal and typed my name.

## Safety

Use only on computers you own or have permission to test. Review payloads before running them.
