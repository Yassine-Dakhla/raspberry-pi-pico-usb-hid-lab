# HID Demonstrations

This directory is reserved for small, documented, harmless HID demonstrations.

## Rules for examples in this repository

- Use only computers you own or have explicit permission to test.
- Clearly describe what each example types or does.
- Keep demonstrations non-destructive and visible to the person running the test.
- Do not include credential theft, stealth, persistence, security-control evasion, or destructive actions.
- Record the operating system, keyboard layout, expected behavior, and actual results.

The first basic keyboard test lives in `src/code.py`. It types a single informational line after a short countdown; no separate payload file is needed yet.
